# Mini3 宠物小应用

## 生生语音桌面

原生桌面皮肤与下面的养成小应用是两个入口。生生语音桌面随固件启动，
使用像素宠物表现待机、聆听、思考、说话和情绪，保留原语音助手的对话、字幕、
音乐、闹钟和按键逻辑。功能键单击按原桌面规则开始／停止语音交互。
此入口没有运行 Lua 小应用，因此不会进入限制闲聊和其他工具的小应用会话模式。

```sh
source ./arcs-sdk/env.sh
./build.sh -S ./apps/arcs-mini -B build-shengsheng-mini3 \
  -DBOARD=arcs_mini3 -DCONFIG_FILES=shengsheng.conf
bash adb_download.sh -S res/arcs-mini3 -B build-shengsheng-mini3 app
```

仅 Mini3 可启用 `CONFIG_SHENGSHENG_AVATAR`，默认固件仍使用原皮肤。
此配置只更换桌面形象和显示名称，**不会自动修改声学唤醒词或云端人设**。
目标唤醒词是“你好生生”；在安装其专用模型之前，仍需使用设备当前提示的原唤醒词，
或单击功能键发起对话。模型制作和后续 Codex 中转方案见
[生生集成说明](../../../docs/shengsheng.md)。

下方养成小应用沿用 `/miniapp/tamagotchi.lua` 和原存档，宠物名字统一为生生。
养成进度与原生语音桌面的动画尚未联动；运行养成小应用期间仍沿用小应用的语音范围限制。

## 拓麻风格电子宠物

`tamagotchi.lua` 使用单色 LCD 配色和逐像素精灵，提供孵化、成长、喂食、清洁、
生病与治疗、睡眠和接星星小游戏。与团团使用独立的小应用 ID 和存档。

在连接设备的电脑执行，上传成功后立即运行：

```sh
adb push apps/arcs-mini/miniapps/tamagotchi.lua /miniapp/tamagotchi.lua
```

顶部六个菜单从左到右为：喂食、游戏、清洁、医药、灯光、状态。

| 操作 | 效果 |
| --- | --- |
| 单击功能键 | 选择下一个菜单；食堂内切换正餐／点心；游戏中显示提示 |
| 快速双击 | 确认当前菜单；进入食堂后，再双击喂所选食物 |
| 游戏中双击 | 星星靠近中央时跳起接住它，增加快乐、消耗精力 |
| 快速三击 | 返回宠物，选中第一个菜单 |
| 长按功能键 3 秒 | 退出小应用，回到系统桌面 |

多击每两次点击间隔应小于约 330 毫秒。灯光菜单负责睡觉／叫醒。
状态菜单显示饱食、快乐、清洁、健康、精力、便便数、年龄和代数。
唤醒设备后，可通过云端小应用动作路由说“给生生吃饭”“打扫便便”“给生生吃药”
“让生生睡觉”“叫醒生生”“查看宠物状态”等；语音路由仍依赖云端支持。

这是成长速度加快的体验版：蛋约 20 秒孵化；孵化后约 5 分钟进入儿童期，
约 30 分钟成年。成年时依据健康、快乐和清洁，分成尖耳型或圆团型。
年龄只在应用运行时增加，重启和退出期间暂停，不对离线时间追加饥饿惩罚。

饱食、快乐、清洁和精力会缓慢下降，每 8 分钟需要打扫一次便便。
连续忽视饥饿或卫生会生病；吃药后仍需喂食和清洁，否则可能再次生病。
长期不照顾导致健康归零时进入纪念画面：选中最右的状态菜单，双击可领养新蛋。
正常成长中的宠物不会被此菜单重置；语音 `new_egg` 动作必须明确传 `confirm=true`。

养成数据每 60 秒尝试保存，主动照顾时在 10 秒写入间隔允许的情况下提前保存。
需要设备已校时，有效期 30 天；未校时时保留旧存档，待校时成功后恢复。
应始终使用 `/miniapp/tamagotchi.lua` 路径。提示音可通过 `set_sound` 操作关闭。

源码只驻留 PSRAM，设备重启或退出后需重新上传，当前没有开机自启动。
需要 API 5、240×240 屏幕和 `CONFIG_MINIAPP_ADB_DEBUG`，详见
[小应用文档](../../../docs/miniapp.md)。

## 团团桌宠

`desk_pet.lua` 是面向 Mini3 240×240 屏幕的本地 Lua 小应用，使用现有固件的 API 5，
不需要改固件。包含小猫呼吸、眨眼、摸摸、吃鱼、毛线球和睡觉动画，以及饱食度、
心情、精力和亲密等级。动画约每秒更新 10 次，不依赖网络素材。

在连接设备的电脑执行：

```sh
adb push apps/arcs-mini/miniapps/desk_pet.lua /miniapp/desk_pet.lua
```

上传成功后立即进入桌宠。需要固件启用 `CONFIG_MINIAPP_ADB_DEBUG`，完整说明见
[小应用文档](../../../docs/miniapp.md)。

| 操作 | 效果 |
| --- | --- |
| 单击功能键 | 摸摸；睡觉时叫醒 |
| 快速双击 | 喂小鱼；睡觉时叫醒 |
| 快速三击 | 睡觉／叫醒 |
| 长按功能键 3 秒 | 退出，返回原桌面 |
| 唤醒后说“摸摸团团”“给团团喂食”“陪团团玩”“让团团睡觉”“叫醒团团” | 由云端通过已声明的小应用操作执行 |

每次点击之间需小于约 330 毫秒。多击等待结束后执行一个操作，不重复执行前面的单击。
语音操作依赖现有云端的小应用动作路由，按键操作和动画可离线使用。

睡觉恢复精力，玩耍消耗少量精力；长时间无人操作时各项属性缓慢下降，不会死亡。
只有主动互动才发出短提示音，可通过 `set_sound` 操作静音。

进度使用小应用 `storage` 持久化，每 30 秒自动保存，主动互动时在写入间隔允许的
情况下提前保存。存档需设备已校时，有效期 30 天；未校时不覆盖旧存档。
应始终上传到相同的 `/miniapp/desk_pet.lua` 路径，才能复用进度。

小应用源码只驻留 PSRAM，设备重启或退出后需重新上传；此版本不改变原系统桌面，
也没有开机自启动。运行小应用时，系统保持屏幕正常亮度，仍遵循原电源与低电量关机策略。
