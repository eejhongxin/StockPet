# 生生股票盯盘

首次启动默认显示乐鑫科技（A 股科创板 `688018`，人民币）与英伟达（美股 `NVDA`，美元）。
现在支持通过原有按键语音添加、删除和查看自选股，最多保存 6 只。
按本次选择仅显示行情，不启用价格、涨跌幅提醒或播报。

## 设备上怎么看

联网后，生生待机桌面显示自选股票的最新可用价格、相对昨收涨跌额／百分比，
以及行情源的日期和时间。`中` 为北京时间，`ET` 为纽约时间（自动按夏令时换算）。
两边各按自己的交易所本地时区处理，不把网络请求完成时间当成行情更新时间。

开始说话后返回原来的生生语音界面，结束对话再显示行情。原功能键和语音唤醒方式继续使用。
本功能直接由设备联网取数，无需电脑或 Codex；也没有进入 Lua 小应用模式。
按一下功能键，等生生开始听，再说：

- “帮我添加苹果股票。”
- “把贵州茅台加到自选股。”
- “添加 AAPL。”（股票名称有歧义时说准确代码）
- “删除英伟达。”
- “看看我现在有哪些自选股。”

生生通过 `stock_watchlist` 语音工具操作实际设备列表；收到成功结果才表示已保存。
名称通过腾讯搜索匹配，新增前必须再取得该代码的有效报价。存在多只同名／近似股票时
返回候选并请你给具体代码；不会随便选第一只。搜索或行情验证失败时不添加。
A 股支持沪、深、北交易所的股票；美股支持行情源可返回的股票代码。
也可说完整代码，例如 `sh600519`、`sz000001`、`usAAPL`。`USB` 是完整美股代码，
显式美股市场前缀写作小写 `us` 后接大写代码，避免与 USB 等代码混淆。

待机每页显示一只股票，默认手动停留，不再自动换页：

页面以股票名称、大号现价和分时曲线为主，代码旁标明 CNY／USD，右侧显示页码和手动／自动状态。
生生缩为角标，按键说明不再常驻占屏。图下方居中的是曲线日期与时区，底部“报价”一行是最新报价的来源时间。
页面不常驻显示行情提供方名称，只保留“可能延时”、休市、离线或失败等状态提示。

- 单击功能键：继续使用原来的语音对话，可添加、删除、查看股票。
- 快速双击：切换下一只自选股；自动轮换开启时，双击也会停回手动模式。
- 快速三击：打开／关闭每 8 秒自动轮换。

按钮只在行情桌面接管双击／三击；对话、拍照、闹钟、OTA 和小应用仍沿用各自操作。
新增和删除后列表保存在设备 KV，
正常重启后继续使用；移除全部股票后显示语音添加提示。重复添加不会占用名额，满 6 只时需先删除。
每次处理一只股票，查询或保存过程中可继续正常处理语音事件。

“看看自选股”工具结果包含设备已有报价、来源时间与延时说明。普通闲聊式问价是否调用工具
由云端语音模型决定；需要设备当前数据时明确说“查看自选股行情”。本轮不增加交易或价格提醒。

常规交易时段约每 15 秒取一轮，否则约每 60 秒（请求耗时另计）。
A 股按周一至周五 09:30–11:30、13:00–15:00 北京时间，美股按周一至周五
09:30–16:00 纽约时间调度。节假日、半日市及临时停牌没有内置日历；
“时段参考”只表示常规时间表，不保证交易所当时开市。

显示 `旧报价` 表示在常规交易时段内，行情时间已比设备时钟旧 3 分钟以上，
或异常领先设备时钟超过 1 分钟。显示 `休市段` 时仍保留最近报价及日期；
例如周末正常会看到周五数据。设备未校时时显示等待校时，不对新旧作判断。
断网或请求失败保留已有价格，同时明确提示；恢复网络后自动重试。

沿用原有电源策略：USB 供电不会因待机进入深度休眠，空闲 30 秒后会降低亮度；
电池供电仍可按原策略休眠／低电关机。行情刷新不伪装成用户活动。

## 分时曲线

每只股票显示腾讯提供的最近交易日常规时段分时价格。A 股只画 09:30–11:30、13:00–15:00，
午休留空、不连线；美股只画纽约时间 09:30–16:00。曲线只包含行情源实际返回的分钟点，
缺失点和未到的时间不补线，只有一个点时仅画点。虚线参考昨收。
曲线与上方最新报价分别获取，因此刷新时间或交易时段可能不同；图旁标明自己的数据日期和时区，
最新报价标明自己的时间。周末和休市可能显示最近交易日曲线。

切换股票优先显示该股票的缓存，首次加载显示等待；更新失败保留该股票已有曲线并提示。
后台请求不会阻塞语音和按键，列表增删与网络请求并行时不会把旧股票的曲线错画到新股票。

## 数据来源

公开报价端点：`https://qt.gtimg.cn/q=<自选代码列表>`。
分时端点：`https://web.ifzq.gtimg.cn/appstock/app/minute/query?code=<A股代码>`，
美股使用同主机的 `UsMinute/query`。每只股票独立缓存，仅刷新当前显示的曲线。
名称搜索端点：`https://smartbox.gtimg.cn/s3/?v=2&t=all&q=<查询词>`。无须行情 API Key。
美股界面标明“可能延时”；此端点没有提供可依赖的延迟／服务保证，
不称为交易所逐笔实时行情。请求频率也不等于源数据更新频率。
如后续需要有保证的美股实时数据，可替换为用户提供的授权行情源。

原始文本含 GBK 名称，解析器仅处理 ASCII 代码、数值和时间，显示搜索源提供的名称（长度有限，屏幕过长时省略）。
报价响应体上限 16 KiB，搜索响应体上限 8 KiB，严格校验完整记录、目标股票、有限数值、日期和数值一致性。
失败退避 30、60、120、240 秒，避免持续高频重试；请求在独立低优先级任务中执行。
实现、API 和解析测试详见 [stock/README.md](../apps/arcs-mini/stock/README.md)。

## 构建与部署

仅 Mini3 配合生生原生桌面启用，默认固件不含此功能：

```sh
source ./arcs-sdk/env.sh
./build.sh -S ./apps/arcs-mini -B build-stock-mini3 \
  -DBOARD=arcs_mini3 -DCONFIG_FILES=stock-watch.conf
bash adb_download.sh -S res/arcs-mini3 -B build-stock-mini3 app
```

这是 CP 应用更新，无需改 AP、Boot 或资源分区，重启后会自动启动行情服务。
切回 `shengsheng.conf` 构建即可回到纯生生语音桌面。股票清单可用语音管理，不需要每次重新编译。

端侧 MCP 工具名称为 `stock_watchlist`，参数 `action` 为 `add`、`remove`、`list`；
添加和删除时 `query` 为用户原始股票名称或代码。网络查询和 KV 写入在独立工作线程执行，
通过原框架异步返回结果，避免阻塞语音事件线程。未修改现有工具名称，也不要求新增平台账号。

本地 ADB shell 可用 `stock status` 查看服务状态、行情源时间、新旧标志及下次请求倒计时；
`stock tools` 查看已注册工具描述，`stock list`、`stock add AAPL`、`stock remove AAPL`
用于诊断同一服务接口；`stock chart` 查看当前选股／曲线日期与点数，
`stock next`、`stock auto` 通过真实按键消息分别模拟双击／三击。
这是调试入口，不需要在日常查看行情时执行。
